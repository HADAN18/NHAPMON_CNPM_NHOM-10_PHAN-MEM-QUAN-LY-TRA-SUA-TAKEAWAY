# NHAPMON_CNPM_NHOM-10_PHAN-MEM-QUAN-LY-TRA-SUA-TAKEAWAY
Xây dựng phần mềm quản lý quán trà sữa takeaway nhằm hỗ trợ chủ quán và nhân viên quản lý sản phẩm, đơn hàng, khách hàng, nhân viên và doanh thu một cách thuận tiện, chính xác và hiệu quả. Phần mềm góp phần đơn giản hóa quy trình bán hàng, tiết kiệm thời gian và nâng cao hiệu quả hoạt động của quán.
